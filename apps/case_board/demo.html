Project Confluence · Case board · Synthetic demonstration case

Invasive squamous cell carcinoma of the cervix (invented demonstration case)

A closed-loop worksheet for the multidisciplinary tumour board. It reads the pathology report into structured findings, then runs care as a cycle: each action has an owner, each result is recorded as an observation, and each observation opens the next action or changes the pathway. Evidence, matched trials and the drug-delivery physics of a fibrotic stroma update with it.

Synthetic case. Not a real patient. Every finding on this page was invented to demonstrate the software. No patient, hospital or report is behind it. For discussion, not a prescription. This board organises published evidence for a treating team and for expert review. It is not a medical device. It does not stage, prescribe or dose. Every option here needs confirmation by the treating gynaecologic oncologist, radiation oncologist and pathologist, using current NCCN / ESMO / FIGO guidance and local availability.

        5 · Stroma & delivery

        Desmoplastic stroma makes delivery a transport problem

        Dense fibrotic stroma lengthens the distance from a capillary to the tumour cells it feeds. A drug or oxygen that diffuses in while being consumed falls off with depth.           8 · Framework

          The same board for any pathology report

          No single drug will cure every cancer. A single pipeline can still turn any pathology report into a structured, evidence-linked strategy in minutes. This synthetic case stands in for a real one. The case lives in one data object in this page, so the next pathology swaps its data and its rule set, not the interface.

          1. Extract

            A language model reads the report into a typed case schema: histology, grade, biopsy edge, stroma, mitoses, imaging size.

          2. Gate

            Rules list the facts the guideline needs that the report lacks: stage, biomarkers, fitness, access.

          3. Map

            A guideline rule set (NCCN / ESMO / national) turns stage and biomarkers into ranked options.

          4. Evidence

            Each option links to its trial, effect size and population, so the board sees why.

          5. Match

            Live ClinicalTrials.gov queries filter trials by stage, biomarker and geography.

          6. Simulate

            Research layer only: transport, PK/PD and the Confluence ODE explore sequencing and delivery questions.

          7. Tumour board

            Humans stage, choose, dose and consent. Nothing leaves the pipeline without this gate.
